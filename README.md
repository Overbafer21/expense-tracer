# Nebula Expense Tracker

Desktop-приложение на Java Swing для учета личных расходов с уникальным тёмным "neon"-дизайном.

## Возможности
- Добавление расходов по категориям.
- Автоподстановка текущей даты.
- Валидация суммы и даты (`YYYY-MM-DD`).
- Удаление выбранной записи.
- Автоматический пересчёт общей суммы расходов.
- Кастомный интерфейс: тёмная цветовая схема, стилизованные кнопки и таблица.

## Технологии
- Java 8+
- Swing / AWT

## Структура проекта
- `ExpenseTracker.java` — основной класс приложения и UI.

## Запуск локально
```bash
javac ExpenseTracker.java
java ExpenseTracker
```

## Идея проекта
`Nebula Expense Tracker` создан как минималистичный и удобный инструмент для ежедневного контроля затрат: быстро добавляйте траты, отслеживайте их по категориям и держите общий бюджет под контролем в одном окне.
